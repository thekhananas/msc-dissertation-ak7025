# Socratic Tutor Research POC

This repository contains the Master's dissertation proposal, engineering documentation, and implementation for a Socratic tutoring research proof of concept.

- `proposal/`: dissertation proposal and references.
- `docs/`: product, architecture, data, and implementation plans.
- `development/`: executable Python, React, simulation, and experiment workspace.

Start development from the nested workspace:

```bash
cd development
pixi run install-web
pixi run check
```

See `development/README.md` for local commands and environment details.
